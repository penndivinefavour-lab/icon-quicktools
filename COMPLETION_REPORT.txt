COLOR PICKER FIX
----------------
Problem: Original code didn't return null for invalid HEX input,
causing NaN propagation and broken preview. HSL roundtrip precision
was also not properly tested.

Root Cause: hexToRgb returned {r:NaN,g:NaN,b:NaN} for invalid input
instead of null, and RGB parse regex didn't validate ranges.

Fix: Rewrote color-converter.js with:
- hexToRgb returns null for invalid input (not NaN)
- Input validation with regex before parseInt
- Proper error messages for partial/invalid input
- Reset button to restore default state
- Robust parseRgb/parseHsl with range validation
- Live preview with swatch text
- 32 regression tests covering all edge cases
